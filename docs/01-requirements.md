# Portfolio Maker

## Project Overview

Portfolio Maker is a full-stack web application that enables users to create a professional portfolio website without writing any code.

The application provides a single smart form where users enter all required information once. After submission, the system automatically generates a responsive portfolio website.

The project is designed to demonstrate modern full-stack development, Docker containerization, and AWS deployment.

---

## Objectives

- Allow users to create professional portfolios easily.
- Reduce manual website creation.
- Generate responsive portfolio websites.
- Provide editing capabilities.
- Deploy using Docker and AWS.

---

## Functional Requirements

### Authentication

- Register
- Login
- Logout

### Dashboard

- Create Portfolio
- Edit Portfolio
- Delete Portfolio
- View Portfolio

### Portfolio Builder

The user should be able to enter:

- Personal Information
- About Me
- Skills
- Education
- Experience
- Projects
- Certifications
- Contact Details
- Social Links
- Resume
- Profile Picture

### Portfolio

- Generate Portfolio
- Preview Portfolio
- Publish Portfolio
